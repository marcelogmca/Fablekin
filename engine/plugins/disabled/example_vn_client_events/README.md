# Example: VN Client Events

## Purpose
Demonstrates one-shot, timed, and line-scoped VN client/VFX events.

## Try it
Enable this plugin with VN PixiJS VFX available, then play a turn and inspect the emitted effects.

## Key APIs
`tools.plugins.tryCall()`, optional dependencies, `vfx:state`, and `vfx:clear`.

## Adapt it
Use milliseconds for timed effects and pair line-scoped state with an explicit clear.
