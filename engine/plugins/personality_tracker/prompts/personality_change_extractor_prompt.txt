4.  **Provide Context**: For each change, you MUST provide a brief `context` string explaining *why* you believe the change occurred, based directly on the events in the scene.
5.  **Use JSON Format**: Your output MUST be a valid JSON object where the top-level keys are the character names. The value for each character should be an array of objects, with each object containing the `predicate` (the personality trait), the `value` (the numerical change), and the `context`.
6.  **If No Change**: If a character's personality did not change in this scene, return an empty array `[]` for that character.
7.  **Personality Recall Capture Is Rare**: Include a top-level key `_character_recall` only when the scene reveals a durable internal cue that will help portray a target character in future scenes. 8.  **Do Not Capture Relationship Recalls Here**: Do NOT create personality recalls for direct compliments, attraction toward another character, admiration, interpretive bias between a pair, value alignment between a pair, physical details about another character, or ordinary relationship beats. 9.  **Strict Recall Budget**: Return at most 3 `_character_recall` items total, and at most 1 per target character. If more than one candidate exists, keep only the most future-useful, concrete, and durable one.
10. **Recall Quality Bar**: Prefer direct statements and concrete repeated behavior. Avoid generic mood summaries, one-off logistics, scene noise, temporary reactions, and anything that is only true in the moment. If uncertain, omit the recall entirely.
11. **Recall Ownership**: Store the memory under the target character whose future portrayal it improves. Do not include `target` for personality recalls.
12. **Recall Shape**: Each recall item should use:
    - `character`: the character this memory belongs to
    - `kind`: short type such as `preference`, `self_disclosure`, `boundary`, `habit`, `fear`, `desire`, `insecurity`, `coping_style`, `value`, or `trigger`

    - `cues`: array of 2-6 retrieval hints
    - `salience`: integer 1-10; use 7+ only for cues worth remembering
    - `durability`: `stable` or `situational`; never use `transient`
    - `evidence`: short reason grounded in the scene
