# Example: Terminal Commands

## Purpose
Shows command registration, argument validation, replies, and a bounded database query.

## Try it
Enable the plugin, then run `/example-ping [name]` or `/example-recent-turns [1-10]`.

## Key APIs
`terminalCommands`, command arguments, `tools.terminal.reply()`, and `tools.db.query()`.

## Adapt it
Validate every argument and place strict limits on user-controlled database work.
