Technical Note: The Persona Engine is a high-level orchestration plugin. It interfaces with the core engine's turn-based sequence logic to inject multi-layered character state and psychological consistency.

Modular Architecture

The Persona Engine replaces monolithic AI responses with four specialized plugins that handle character classification, static assets, internal psychology, and social dynamics separately.

Core Integration: These plugins hook into HOOK_VN_BLOCKING_TASKS to modify character data before the AI Director crafts the dialogue.
OPTIMIZATION

CONSISTENCY

O(1) historical context lookups using consolidated LEDGERS.

01_Character Classifier

This is the gateway plugin. It performs importance triage to determine if a character deserves full psychological tracking or should be treated as transient noise.

Plugin Logic: Intercepts NEW_CHAR_IDENTIFIED event to perform a fast "Major/Minor" check using prompt heuristics.

Triage Heuristics

MAJOR
Named unique entities (e.g. "Cyno"). Full persistence enabled.
MINOR
Generic roles (e.g. "Soldier 1"). Minimal context overhead.

02_Character Sheets

Implements the "Pyramid of Persona". Not every character needs a 4000-token biography.

01: PROTAGONIST FULL DETAIL

Maximum depth. Permanent context injection.

02: CORE COMPANIONS

L1-L9 layer visibility. Dynamic fact evolution.

03: GUEST / MINOR

Lite "Capsule" sheets only. Temporary tracking.

Plugin Logic: Analyzes turn beats and updates vector floats. Every 5 turns, sums the beats into a "Historical Ledger" to save tokens.
