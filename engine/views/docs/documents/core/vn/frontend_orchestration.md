# Viewer Frontend Orchestration

The VN Viewer is built on a modular JavaScript architecture designed to handle complex, non-deterministic narrative payloads from the engine.

## 1. Payload Management (`payload_manager.js`)

This module is the entry point for every new turn generated by the engine.
- **Preloading**: Uses PixiJS `Assets.load` to fetch backgrounds, sprites, and CGs before the scene begins, preventing visual popping.
- **UCP Compilation**: Dispatches the raw sequence to the [UCP Compiler](./ucp_compilation.md) to resolve director commands (zooms, music, transitions).
- **State Cleanup**: Provides `resetViewerState()` to clear all volatile events, overlays, and sprite states when switching stories or chapters.

---

## 2. Generation & Logic Flow (`generation_manager.js`)

Manages the active "Working" state of the engine.
- **Submission**: Handles the `generate-vn-turn` lifecycle, disabling inputs and clearing buffers.
- **System Console**: Implements a real-time log window within the viewer, allowing users to watch the AI's internal thought process (CoT) and pipeline steps.

---

## 3. Narrative Execution (`dialogue_orchestrator.js`)

Responsible for the moment-to-moment experience of reading the story.
- **Typewriter Effect**: A custom-timed interval that types out text based on the user's `write_speed` setting.
- **Auto-Play**: Calculates character-specific pauses and manages the transition between dialogue beats.
- **Sequence Intercepts**: Dispatches signals to the [Intercept System](./intercept_system.md) at the start of each dialogue line, allowing plugins to pause rendering for gameplay or UI overlays.
- **Intercept Actor Sessions**: Intercept runs can spawn scoped plugin actors through `bridge.actors`; these are automatically cleaned on intercept completion and chapter resets.

---

## 4. Director Synchronization (`director_sync.js`)

Reconciles the visual environment with the instructions provided by the [UCP Dispatcher](./ucp_protocol.md).
- **Camera Control**: Translates UCP `cam` commands into PixiJS viewport movements.
- **VFX/SFX Dispatch**: Dispatches global events (e.g., `vfx:sync`) that external plugins can listen for to trigger custom visual effects.
