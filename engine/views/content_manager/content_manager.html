The Basics

Story Scripts are .md files that contain JavaScript. They are executed as project-level plugins.

Plugin Structure

module.exports = {
  id: 'my_unique_script_id',
  hooks: {
    'HOOK_NAME': {
      priority: 10,
      run: async (context, tools) => {
        // Your logic here
      }
    }
  }
};

Common Hooks

  • HOOK_VN_BLOCKING_TASKS: Best for modifying VFX, SFX, or state before a turn renders.
  • HOOK_TURN_START: Runs at the absolute beginning of a new turn generation.
  • HOOK_VN_GUI_READY: Runs when the viewer UI has finished rendering a turn.

Security

All scripts are subject to Trust-On-First-Use (TOFU). If you modify a script, users will be prompted to re-approve it via the SHA-256 hash check.
