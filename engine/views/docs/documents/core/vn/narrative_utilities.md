# Narrative & Text Utilities

The engine includes several low-level utilities to ensure narrative consistency and proper text presentation.

## 1. Text Formatting (`text_formatting.js`)

This utility is responsible for post-processing all text generated by the LLM before it is displayed to the user or processed by the [UCP Compiler](./ucp_compilation.md).

### Placeholder Resolution
The engine resolves explicit player placeholders consistently in prompts and the turn-zero prologue.
- **Name**: `[USER_CHARACTER]` or `<USER_CHARACTER>` uses the configured player-character name.
- **Pronouns**: `[USER_SUBJECT]`, `[USER_OBJECT]`, `[USER_POSSESSIVE]`, `[USER_POSSESSIVE_PRONOUN]`, and `[USER_REFLEXIVE]`.
- **Capitalization**: Append `_CAP` when a pronoun begins a sentence, such as `[USER_SUBJECT_CAP]`.
- **Fallbacks**: Missing pronoun metadata uses neutral `they/them/their` forms; the displayed prologue uses `the protagonist` if no player name is configured.

### Case Normalization
- **Auto-Capitalization**: Ensures that every dialogue line or narrative beat begins with a capital letter, fixing common LLM artifacts in short-form responses.

## 2. Turn Metadata Helpers

These helpers (located in `timeline.js` and `chaptermanagement.js`) calculate metadata for the project ledger:
- **Dialogue Counting**: Calculates the number of spoken lines in a turn to provide "Reading Time" estimates.
- **Thumbnail Mapping**: Associates the [Background Snapshot](../vn/rendering_pipeline.md) of the final frame with the turn record.
- **Synopsis Extraction**: Automatically extracts the summary/synopsis field from the narrative engine's JSON output for use in the Timeline.
