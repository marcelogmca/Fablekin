# Example: PixiJS Intercept

## Purpose
Provides the smallest useful blocking PixiJS takeover.

## Try it
Enable the plugin and enter the VN; click the takeover to return.

## Key APIs
`registerRuntimeIntercept()`, the Pixi payload context, `pluginRuntime`, and lifecycle disposal.

## Adapt it
Release listeners and display objects on finish, abort, timeout, and disposal.
