Adventure Book

Adventure Book turns suitable story moments into bounded storybook challenge loops: investigations, journeys, ruins, hazards, decoding, infiltration, social pressure, and survival scenes. It is intentionally not a full D&D rules engine; it resolves uncertainty from narrative evidence.

Runtime Shape

Director handoff

The plugin registers a CHALLENGE capability and waits for natural decision points after mainline turns.

Book overlay

A blocking VN intercept appears during user input and runs the choice/result loop through socket events.

Continuation handoff

When complete, the transcript is summarized into a clean synthetic user prompt for the next VN turn.

Force Testing

Enable force_offer_every_turn through the user-facing Force Generate Adventure Book setting to bypass Director/classifier eligibility during testing. In this mode, the overlay appears after every mainline turn and exposes a debug Rebuild button.

Rebuild expires the current uncommitted session and regenerates the first Adventure Book page from the same parent turn. It does not replay choices, store facts, request CG, or submit the continuation prompt. Canonization still only happens when the final Continue action runs.

Prompt Assets

Adventure Book prompt text is kept in editable .txt files:

  • prompts/initial_page.txt creates the first situation and options.
  • prompts/advance_page.txt continues after a player choice and server-side d20 roll.
  • prompts/final_capsule.txt compresses the transcript into a rich summary and immediate scene ending.
  • prompts/director_description.txt and prompts/director_handoff_hint.txt describe the Director capability.
  • prompts/cg_illustration.txt templates the optional soft-dependency CG request.

Resolution Rules

80% chance -> roll 5+
50% chance -> roll 11+
20% chance -> roll 17+
natural 1  -> critical failure
natural 20 -> critical success

Failure is failure-forward: it changes the context and continues the story instead of dead-ending the loop. Chance and stakes are separate, so a likely option can still be high risk, and a long shot can still be low reward.

Soft Dependencies

cg_generator is optional. If prefer_cg is enabled, cg_model_tier is not none, and the plugin is installed, Adventure Book requests one non-blocking illustration after completion. Missing or failed CG generation never blocks the VN continuation handoff.

Fact Ownership

Adventure Book stores lightweight plugin-scoped facts keyed by the parent turn. Other plugins should filter by their own plugin id before reading fact ownership data.
